# bundle-wiki

The TiddlyWiki in every fxplugins.codecogs.com download for TiddlyWiki: the plugin installed, and
`__FXPLUGINS_LICENCE__`, `__FXPLUGINS_DESIGN__` and `__FXPLUGINS_SAMPLE__` where the visitor's
licence key, design and a page of equations go. `site/js/example.js` (`fillWiki()`) fills them in
the browser. Built by `../test-wiki/build.sh` alongside the test wiki; no server tiddler, so the
plugin loads the editor from its default host.
